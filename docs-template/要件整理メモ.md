## 元の要求（依頼元の言葉）

- 「注文のときにクーポンを使えるようにしてほしい」
- 「割引は率でも金額でも指定したい」
- 「安売りしすぎないように上限をつけたい」
- 「一部の商品はクーポンの対象外にしたい」
- 「配布数を絞りたい」

## 曖昧な点と確認した内容

| 曖昧な要求                   | 確認した内容                                                       |
| :--------------------------- | :----------------------------------------------------------------- |
| 「率でも金額でも」           | 1つのクーポンはどちらか一方。率と固定額の併用はしない              |
| 「上限をつけたい」           | 率のクーポンにのみ上限額を設定できる。固定額には不要               |
| 「対象外の商品」             | 商品単位ではなくカテゴリ単位で除外する                             |
| 「配布数を絞りたい」         | 発行数の上限を持ち、注文確定時に消費する                           |
| クーポンの併用               | **1注文につき1枚まで**（複数適用はしない）                         |
| 割引額が対象額を超える場合   | 対象額までで打ち切る（支払額をマイナスにしない）                   |

## 設計書に落としきれていない判断（試験観点で拾う必要がある）

- **有効期間の境界**: 開始日時は「以上」、終了日時は「未満」で扱う。終了日時ちょうどは無効
- **最低購入金額の境界**: 「超えている」ことを条件にする。ちょうど同額のときは適用しない
- **除外カテゴリの扱い**: 除外分は割引の計算対象から外すが、最低購入金額の判定も除外後の金額で行う
- **発行数上限の同時実行**: 上限の直前で複数の注文が重なったときに、上限を超えて消費されないこと
- **カートが空、または全品が除外カテゴリ**のときの挙動
- **確定前と確定時で結果が変わる場合**: カート確認で適用できたクーポンが、注文確定までの間に期限切れ・上限到達になることがある

## 対象外（今回やらないこと）

- クーポンの管理画面（発行・停止）
- ユーザーごとの利用回数制限
- 送料への割引適用
