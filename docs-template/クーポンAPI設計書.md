# クーポンAPI設計書（リハーサル用ダミー）

> **これはリハーサル用のダミーである。** 本来はNo.2（02-02 API設計書作成）で受講者が作成するもので、
> リハーサルではNo.2の演習を行わないため、No.3の手順（03-01〜03-03）を実行できるようにするために置いてある。
> 中身の妥当性は問わない。

## データモデル

### Coupon

| 項目                  | 型            | 説明                                                   |
| :-------------------- | :------------ | :----------------------------------------------------- |
| `code`                | 文字列・一意  | クーポンコード                                         |
| `type`                | 文字列        | `percentage`（率）または `fixed`（固定額）             |
| `value`              | 整数          | `percentage`なら割引率(%)、`fixed`なら割引額(円)       |
| `max_discount_amount` | 整数・任意    | 率のときの割引上限額。固定額では使わない               |
| `min_purchase_amount` | 整数          | 適用に必要な最低購入金額。既定は0                      |
| `excluded_categories` | 配列・任意    | 割引の対象外とする商品カテゴリ                         |
| `usage_limit`         | 整数・任意    | 発行数の上限                                           |
| `used_count`          | 整数          | 消費済みの数。注文確定時に加算する                     |
| `valid_from`          | 日時          | 有効期間の開始                                         |
| `valid_to`            | 日時          | 有効期間の終了                                         |

### Order（既存に追加）

| 項目              | 型           | 説明                             |
| :---------------- | :----------- | :------------------------------- |
| `coupon_code`     | 文字列・任意 | 適用したクーポンのコード         |
| `discount_amount` | 整数         | 実際に割引した金額。既定は0      |

## 割引額の求め方

1. カートの商品のうち、`excluded_categories`に含まれるカテゴリを除いた金額を**割引対象額**とする
2. 割引対象額が`min_purchase_amount`を**超えていない**場合は適用しない
3. 割引額を求める
   - `fixed`: `min(value, 割引対象額)`
   - `percentage`: `round(割引対象額 × value ÷ 100)` を求め、`max_discount_amount`があればそれ以下に丸める
4. いずれの場合も割引額は割引対象額を超えない

## API

### POST /cart/coupon（新規・要認証）

カートにクーポンを適用してプレビューする。まだ注文は確定しない。

- 入力: `{ "code": "SPRING10" }`
- 出力: 割引対象額・割引額・割引後の合計

| 状況                         | ステータス |
| :--------------------------- | :--------- |
| 適用できた                   | 200        |
| コードが存在しない           | 404        |
| 有効期間外                   | 422        |
| 最低購入金額を満たさない     | 422        |
| 発行数の上限に達している     | 409        |

### DELETE /cart/coupon（新規・要認証）

適用中のクーポンを外す。カートの状態を返す。

### GET /cart（既存・拡張）

適用中のクーポンコード・割引額・割引後の合計を含めて返す。

### POST /orders（既存・拡張）

注文を確定する。**確定時にクーポンを再検証する**（プレビューから時間が経って期限切れ・上限到達になっている可能性があるため）。

1. クーポンを再検証し、割引額を求め直す
2. 発行数を1つ消費する。上限に達していて消費できなければ409を返す
3. `subtotal`・`coupon_code`・`discount_amount`を注文に記録する

| 状況                     | ステータス |
| :----------------------- | :--------- |
| 確定できた               | 201        |
| 再検証で適用できなくなった | 409 / 422 |

## 動作確認用のクーポン

初期データに次のクーポンが入っている。

| コード      | 種別       | 内容                       |
| :---------- | :--------- | :------------------------- |
| `SPRING10`  | percentage | 10%引き                    |
| `FLAT500`   | fixed      | 500円引き                  |
| `WELCOME5`  | percentage | 5%引き                     |
| `NOACC15`   | percentage | 15%引き・一部カテゴリ除外  |
| `SOLDOUT`   | fixed      | 発行数の上限に達している   |
| `EXPIRED20` | percentage | 有効期間を過ぎている       |
